## キャラクター作成とハブ：アイデンティティの確立

ゲーム内の旅は、賑やかなマルチプレイヤーの世界ではなく、「ハブ（Hub）」と呼ばれる隔離された準備空間から始まります。ハブは、あなた専用の更衣室兼準備室のような場所です。共有ワールドに出現した瞬間、他のプレイヤーはあなたの外見、ステータスを示す装飾、プロフィールのタグを即座に見極めるため、ここでじっくり時間をかけることが極めて重要になります。

```
+-------------------------------------------------------------+
|                          ハブ（THE HUB）                    |
|  - 名前、苗字、身長、衣装、種族のカスタマイズ               |
|  - 初期アクセサリーの装備 ＆ プロフィールの決定             |
+-------------------------------------------------------------+
                              │
                              ▼ (転送ポータル)
+-------------------------------------------------------------+
|                        国（THE PROVINCE）                   |
|  - オープンワールド・マルチプレイヤー・ロールプレイ         |
|  - 農地、商人の屋台、銭湯、住宅                             |
+-------------------------------------------------------------+
```

ハブの中でアイデンティティを設定した後、転送ポータルを通って「国」へと足を踏み入れます。プレイヤーの経験則上、見た目の選択によって、侍、商人、役人からの扱われ方が大きく左右されます。もし「竜神（Ryūjin）」のようなファンタジー種族を選択する場合は、その出自がキャラクターの生い立ちや公の場での振る舞いにどのように影響するかを考慮すると良いでしょう。

| カスタマイズ項目 | ロールプレイへの影響 | コミュニティの推奨事項 |
| :--- | :--- | :--- |
| **名前 ＆ 苗字** | 家系や社会的地位を確立する | 江戸時代の慣習に合った、歴史的背景を感じさせる名前を選ぶ |
| **種族（例：竜神 / Ryūjin）** | 視覚的な華やかさと独自の存在感 | 後から種族を変更するには再カスタマイズが必要なため、慎重に選択する |
| **体格 ＆ 身長** | 人混みの中での存在感を決定づける | 目指す役職に合わせたプロポーションにする（例：大柄な護衛、小柄な職人） |
| **衣装 ＆ 髪型** | キャラクターの現在の財力を伝える | 最初は質素な平民の服から始め、「両」を稼いだ後にアップグレードする |
| **プロフィール（Bio） ＆ タグ** | 他のプレイヤーに背景ストーリーを伝える | 他のロールプレイヤーが素早く読めるよう、簡潔にまとめる |

外見を確定すると、ゲートを通って「Welcome to the Province（国へようこそ）」のマイルストーンがアンロックされます。最初の外見ですべての運命が固定されるわけではありませんが、統一感のある見た目でスタートすることで、初期の交流が格段にスムーズになります。

## 経済と「両（Ryō）」：初期の労働とキャリアパス

この世界の主要通貨は**両（Ryō）**ですが、スポーンしたばかりのキャラクターはほぼ一文無しの状態です。どのような**shogun s reign tutorial**においても、最優先事項は予測可能な収入ループを確立することです。「両」がなければ、商人の商品を仕入れたり、住宅を確保したり、より良い装備を整えたりすることはできません。

コミュニティの報告によると、正確な賃金計算式やNPC商人の価格設定は開発者によって定期的に調整されますが、基本的な稼ぎの流れは一貫しています。初日に最も頼りになる収入源は、肉体労働と交易です。

| 初心者向け役職 | 主なゲームプレイループ | 収益性 | おすすめのプレイヤータイプ |
| :--- | :--- | :--- | :--- |
| **農民（Farmer）** | 畑の手入れ、作物の収穫、収穫物の売却 | 安定、低リスク | 確実なソロ収入を得たい初心者 |
| **商人（Merchant）** | 物資（カブ、キャベツなど）のまとめ買い、屋台での販売 | 上限が高い、元手が必要 | 交易、値引き交渉、在庫管理を楽しみたいプレイヤー |
| **湯守・給仕（Attendant）** | 銭湯で客の案内や世話、接客業務を行う | 中程度、チップに依存 | 雰囲気への没入感を重視する交流派ロールプレイヤー |
| **芸能者（Performer）** | 観客の前で音楽リズムミニゲームを演奏する | 腕前に依存 | タイミングに自信があり、演奏バッジを狙うプレイヤー |

### 農業のルーティン
完全な初心者の場合、「農民」の役職が最も安全な出発点となります。畑を耕し始めるための初期資金は必要ありません。作物を収穫して集荷場所へ運ぶことで、経済的な損失リスクを負うことなく、初期の「両」を蓄えることができます。

### 商人の取引サイクル
農業である程度の「両」を貯めたら、「商人」の役職へ移行することでより高い利益率を狙えます。卸売りの農産物（定番のカブやキャベツなど）を買い付け、空いている市場の屋台に店を構えます。商人として成功するには、通りがかる旅人に声をかけ、適正な価格で交渉し、サーバーのピーク時間帯に在庫を切らさないといった積極的な立ち回りが求められます。

コミュニティのアナウンスやアップデート情報を追うには、[Roblox上のShogun's Reign公式ページ](https://www.roblox.com)をチェックして、ゲームバランスの調整やサーバーイベントの最新情報を把握しておきましょう。

## 社会的エチケットと江戸ロールプレイの作法

一般的なアクションゲームとは異なり、この世界はロールプレイのエチケットを強く重んじます。サーバーをただの戦場のように扱うと、町の衛兵や貴族の間ですぐに悪評が広まってしまいます。社会的な作法を理解することは、本**shogun s reign tutorial**における中核的な必須知識です。

```
[村に到着] ──> [現地の慣習を観察] ──> [屋内のルールを遵守] ──> [社会的地位の獲得]
```

物理的な空間を尊重することが、生存のための第一歩です。屋内の施設、特に茶屋、武家屋敷、共同浴場（銭湯）では、特定の振る舞いが求められます。

*   **脱靴（履物を脱ぐ）：** 畳の上に上がる前や、清潔な共同浴場の床に入る前には、必ず草履や下駄を脱いでください。
*   **身分・肩書への敬意：** 家臣、侍、または役人の正式な肩書を持つキャラクターに対しては、丁寧な挨拶が求められます。上位の人物に話しかける前に一礼することで、無用なトラブルを防げます。
*   **シーンの整合性を保つ：** 不自然なジャンプを繰り返したり、世界観を壊すような（メタな）チャットを送信したりして、進行中のドラマチックな会話や個人的な商談を妨害してはなりません。
*   **戦闘の規律：** 双方が合意した組織的な抗争や正式な決闘でない限り、武器は常に鞘に収めておきましょう。

| 場所 | 求められるエチケット | 避けるべき典型的なミス |
| :--- | :--- | :--- |
| **銭湯** | 履物を脱ぐ。礼儀正しく静かに交流する | 湯船の中を走り回る、好戦的な態度を取る |
| **市場** | 順番を守って並ぶ。他人の屋台を尊重する | 商人の台の上に直接乗る、チャットを連投（スパム）する |
| **貴族の屋敷** | 入る許可を待つ。衛兵には丁寧に接する | 同行者なしで私室に無断侵入する |
| **農地** | 使用中の畑を尊重する。作物を踏み荒らさない | 他のプレイヤーが作業中の収穫ポイントを横取りする |

これらのコミュニティ規範を守ることで、既存の派閥、ギルド、家臣団から受け入れられやすくなり、さらなる出世の道が開かれます。

## 住宅と不動産：拠点の確立

農業や商売で十分な「両」を蓄えたら、家を確保することが中盤の主要目標となります。購入・確保可能な物件は国中に点在しており、道沿いの簡素な小屋から村の大きな屋敷まで多岐にわたります。

正確な購入費や維持費は公式には発表されておらずプレイヤーの体験によって異なりますが、家を所有することには確かなメリットが複数存在します。

1.  **個人的なロールプレイ空間：** 人目を気にせず、茶会や秘密の氏族会議、商談を主催できる。
2.  **ステータスの証明：** 物理的な物件を所有していることは、単なる流れ者の労働者ではなく、コミュニティに定着した一員であることを周囲に示す。
3.  **保管とカスタマイズ：** キャラクターの個性、職業、社会的階級を反映した内装に整えることができる。

| 物件の種類 | 推定投資規模 | 主な用途 | 最適なプレイヤー |
| :--- | :--- | :--- | :--- |
| **庶民の小屋（Commoner Cottage）** | 少〜中程度の「両」 | 基本的な住居、控えめな暮らし | 初期の農民、孤独な職人 |
| **商家の店舗兼住宅（Merchant Shophouse）** | 中〜高程度の「両」 | 住居と店舗の兼備 | 活発な市場の商人、クラフト職人 |
| **大屋敷・館（Estate Compound）** | 高〜最高峰の「両」 | 氏族の本部、家臣の待機所 | 貴族の家系、侍の派閥 |

貯金を投じる前に、さまざまな地域を下見しておきましょう。主要な街道沿いにある物件は商人にとって抜群の集客力を誇り、人里離れた森の住居は物静かな学者や熟練の芸能者に平穏をもたらします。

## 長期的な進行：平民から将軍へ

このゲームにおける進行は、単に小銭を貯めることだけではありません。それは進化し続ける「出世街道」です。すべてのキャラクターは位のない平民としてスタートしますが、あなたの選択次第で、国内の階層をどこまでも登り詰めることができます。

```
平民（農民 / 職人）
            │
            ▼
商業階級（商人 / 店主）
            │
            ▼
武官・従者階級（家臣 / 警護 / 武士）
            │
            ▼
貴族階級（朝廷役人 / 貴族）
            │
            ▼
      将軍職（最高指導者）
```

本**shogun s reign tutorial**でも解説している通り、商業階級を超えて上を目指すには、他者との同盟関係の構築が不可欠です。侍や忠実な家臣になるには、通常、名のある領主に仕え、警護任務を通じて忠誠を示し、領内の紛争で氏族の名誉を守る必要があります。

究極の称号である**「将軍（The Shogun）」**への到達は、サーバー全体の広範な支持を集めるか、巧みな政治工作を成功させた影響力あるリーダーにのみ許された極めて稀なマイルストーンです。ただし、最高位の座に就くことには大きな危険も伴います。対立派閥が反乱を起こせば、不安定な治世はあっけなく終わりを迎えることになります。

## 主要なバッジとマイルストーン目標

バッジは、キャラクターの生涯にわたる功績を追跡するための貴重なロードマップとなります。やみくもに行動するのではなく、これらのマイルストーンを目安にして、自身のロールプレイの目標を定めましょう。

| バッジ名 | 解除条件 | 戦略的意義 |
| :--- | :--- | :--- |
| **Welcome to the Province** | ハブからメインワールドへテレポートする | 冒険の旅の始まりを示す |
| **Instrument Master** | 芸能者として完璧な演奏を披露する | リズムミニゲームの腕前を証明し、芸術的知名度を獲得する |
| **Ambitionless** | 将軍を目指すことなく一生を全うする | 質素で平穏な職人ライフを送ったプレイヤーを称える |
| **The Shogunate** | 最高指導者である「将軍」に任命される | サーバー内における政治・軍事指導者の頂点 |
| **Reign's End** | 領内の反乱により権力の座から失脚する | 劇的な政変と王朝の交代を記録する |

これらの実績は、成功には多くの形があることを証明しています。「Ambitionless（無欲）」のマイルストーンのように静かな満足を求めるか、あるいは絶対的な支配を目指すかにかかわらず、この世界はその両方の生き方を歓迎してくれます。

## スムーズなスタートを切るための初心者向け重要ヒント

最初のプレイセッションを最大限に有意義なものにするために、コミュニティから寄せられた実践的なヒントを心に留めておきましょう。

*   **ハブから慌てて出ないこと：** キャラクターの名前や服装の調整には十分に時間をかけましょう。第一印象が、国での派閥からの扱われ方を決定づけます。
*   **手元の資金（流動資産）を残しておく：** 贅沢な装飾品や住宅の購入に「両」をすべて使い果たしてはなりません。商人の仕入れや予期せぬ出費に対応できるよう、常に十分な手元資金を確保しておきましょう。
*   **話す前に周囲を観察する：** 人の多い茶屋や番所に到着した際は、その場の空気を掴むために、進行中の会話を読んで様子を見ましょう。
*   **他の労働者と協力する：** 他の農民や商人と手を組むことで、運搬作業を分担し、人里離れた道で現れる盗賊からお互いを守ることができます。
*   **公式・検証済みの情報を確認する：** 無料のアイテムコードや通貨の裏技を謳う外部の情報には注意してください。現在、この作品に公式のプロモーションコードは存在せず、正当な進行はすべてゲーム内での労働によってのみ得られます。

本**shogun s reign tutorial**の指針に従うことで、生き残り、財を成し、永続的な影響力を築くための確かな足がかりが得られます。焦らず時間をかけ、現地の慣習を尊重しながら、国を舞台にあなただけの物語を紡いでいってください。

## よくある質問（FAQ）

### ゲーム内に公式のShogun's Reignチュートリアルは組み込まれていますか？
最初のハブ内に基本的なUIツールチップや導入案内は用意されていますが、手取り足取り指示されるような固定クエストラインはありません。プレイヤーは、探索やコミュニティとの交流、そして本**shogun s reign tutorial**のような外部ガイドを通じて、より深い経済や社会システムを学んでいくことになります。

### 初心者がソロで「両」を最も早く稼ぐ方法は何ですか？
「農民」として農地で働くことが、ソロ初心者にとって最も確実な初期の金策と広く見なされています。農業は初期投資が不要で、安定した収益が得られるため、その資金を元手に、より利益率の高い「商人」の事業へとステップアップできます。

### 一度獲得した「将軍」の称号を失うことはありますか？
はい。将軍の地位は、一度獲得したら失われない恒久的なスキン肩書ではありません。政情不安が高まったり、対立派閥によるクーデターが成功したりすると、支配者はその座を追われ、劇的な「Reign's End」の実績バッジが付与されます。

### 無料の「両」がもらえる有効なプロモーションコードはありますか？
コミュニティの記録および開発者の発言によると、現在ゲーム内に有効なプロモーションコードやコード引き換え機能は存在しません。秘密のコードを謳う不審なWebサイトや動画には十分ご注意ください。
