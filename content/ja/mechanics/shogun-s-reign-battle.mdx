## 基本戦闘メカニクスとアクション・エコノミー

『Shogun's Reign』における戦闘の根幹は、スタミナ消費、体勢防御、攻撃タイミングという相互に連動した三要素を中心に展開します。あらゆる攻撃の振り、防御ブロック、回避アクションはスタミナを消費します。スタミナが完全に枯渇するとガードブレイク（体勢崩し）が発生し、相手の強力なクリティカル攻撃に対して完全に無防備となってしまいます。

```
[防御ガード] ---> [パリィ受付時間] ---> [体勢崩し（ガードブレイク）] ---> [クリティカル攻撃]
     ^                                                                      |
     |---------------------- [復帰＆リセット] <------------------------------|
```

プレイヤーの経験則やコミュニティの報告によれば、無謀な攻撃を仕掛けるよりも、忍耐強く立ち回る方がはるかに優れた戦果をもたらします。崩しの布石や角度を作らずに構えている相手のガードへやみくもに斬りつけても、相手より早く自分自身のスタミナを枯渇させるだけです。

戦闘中の行動がアクション・エコノミーに与える影響を把握するために、以下の内訳表を参照してください：

| 戦闘アクション | スタミナ消費量 | 体勢への影響 | 発生フレーム/受付時間 | 主な戦術的用途 |
| :--- | :--- | :--- | :--- | :--- |
| **弱斬り（Light Slash）** | 低（10–15%） | ヒット時：中 / ガード時：低 | 高速（発生0.25秒） | 相手の初動の阻止、防御の牽制・探り |
| **強斬撃（Heavy Cleave）** | 高（25–35%） | ガード時：高 / ガードブレイクの危険性 | 低速（発生0.65秒） | 守りを固める敵への崩し、壁際への追い詰め |
| **防御ガード（Defensive Guard）** | ガード成功ごとに消費 | 体勢ゲージを削りつつダメージを吸収 | 即時切り替え可能 | 削りダメージの軽減、パリィへの布石 |
| **受け流しパリィ（Deflective Parry）**| 極小（5%） | 攻撃側の体勢ゲージを大幅に削る | 厳格（受付時間0.15秒） | 攻守の主導権逆転、決定的な隙の創出 |
| **戦術ステップ/回避** | 中（20%） | なし | 即時の無敵時間 | 位置取りの変更、広範囲な薙ぎ払いの回避 |

受け流しパリィの習得は、最もリターンの高いスキルです。パリィを失敗すると胴体に直撃を受けるリスクがありますが、成功すれば相手を一瞬で体勢崩れに追い込み、あらゆる激戦の **shogun s reign battle** で主導権を握ることができます。

選択する武器は、キャラクターの機動性プロファイル、リーチ、脅威範囲を直接決定づけます。すべての武器を画一的に扱おうとする戦士は、[公式Robloxゲーミングプラットフォーム](https://www.roblox.com)上で相性の悪さを的確に突いてくる熟練の決闘者に苦戦を強いられることになります。

```
       [薙刀 / 槍]  （長リーチ、攻撃後の隙が大きい）
            ^
            |   （ゾーニング・間合いの優位性）
            v
       [標準的な刀]  （バランスの良い速度、柔軟なパリィ性能）
            ^
            |   （インファイトの優位性）
            v
       [短刀 / 懐剣]  （超近接戦、素早い連撃）
```

『Shogun's Reign』の武器は、歴史に基づいた明確なアーキタイプに分類されます。刃付きの長柄武器は開けた街道や野原での小競り合いを支配し、小型のサイドアームは狭小な茶屋や入り組んだ住宅街の路地裏で真価を発揮します。

| 武器タイプ | リーチ階級 | 攻撃ペース | ガードブレイク性能 | 最適な戦術的役割 |
| :--- | :--- | :--- | :--- | :--- |
| **標準的な刀（Katana）** | 中 | バランス型 | 中 | 万能な決闘、カウンター攻撃、オールラウンドな対応 |
| **薙刀（長柄武器）** | 長 | 低速〜中速 | 高 | 集団戦の制御、チョークポイントの封鎖、外周防衛 |
| **野太刀（大太刀）** | 超長 | 低速 | 極めて高い | 前衛での広範囲薙ぎ払い、敵前線の突破 |
| **脇差 / 短刀** | 短 | 極めて高速 | 低 | 奇襲戦、狭い屋内での接近戦、側面への回り込み |

武器を選ぶ際は、所属するクランや組織内での自身の役割を考慮してください。前衛護衛には要人（VIP）に敵を近寄らせない薙刀の広い薙ぎ払いが必要です。一方で、隠密任務を行う工作員や街の旅人には、懐に隠せる脇差の素早い抜刀速度が有利に働きます。

## 間合い、フットワーク、地形の活用

規律ある戦士は、武器のリーチだけに頼ることはありません。足運びこそが、戦いを勝利で終えるか敗北で終えるかを決定づけます。動的な **shogun s reign battle** を生き抜くには、高低差、角のトラップ、露店、橋、日本家屋の縁側などの障害物を常に計算に入れる必要があります。

フットワークは3つの交戦ゾーンを中心に展開します：

1. **ニュートラルゾーン（安全圏）：** 双方の武器のリーチ外。ここでは前後にフェイントを入れ、相手の無駄振りを誘い出します。
2. **スレットゾーン（脅威圏）：** 戦闘中の最も長い武器の切っ先が届く範囲。リーチで劣る場合、ガードなしでこのゾーンに留まるのは致命的です。
3. **グラップル/ツバ迫り合いゾーン（超至近距離）：** 胸が触れ合うほどの距離。この間合いでは長柄武器は梃子の利かない無力なものとなり、素早い短柄武器の使い手が圧倒します。

| 間合いゾーン | 主な脅威 | 理想的な防御手段 | 反撃の戦術 |
| :--- | :--- | :--- | :--- |
| **遠距離（3m以上）** | ダッシュ攻撃、突進、投擲物 | サイドステップまたは距離の維持 | ダッシュ攻撃を空振りさせ、バックステップ後に硬直を突く |
| **中距離（1.5–3m）** | 標準的な薙ぎ払い、横斬り | アクティブガード、タイミングを合わせたパリィ | 斜め方向の旋回移動で相手の側面の死角を突く |
| **至近距離（1.5m未満）**| 高速な弱連撃、掴み、目眩まし | バックダッシュまたは前蹴りによる中断 | 素早いジャブ連打から側面への回り込み |
| **狭小エリア（壁際など）**| 壁際への追い詰め、視界不良 | 高段ガード、壁バウンドからの復帰 | サイドステップを防ぐ強力な正面突き |

地形を味方につけることで、絶望的な数的不利さえも覆すことができます。複数の敵に追い詰められた場合は、狭い路地や中庭の入り口へ後退してください。チョークポイント（狭窄路）は、敵を一列に並ばせることで数的優位を無効化し、側面からの挟撃を防ぎます。

## 戦闘戦術における「引きずり＆運搬」機能の活用

コミュニティで高く評価されているユニークなメカニクスの1つが、インタラクティブな「引きずり・運搬（Drag and Carry）」システムです。敗北または行動不能になったキャラクターが単に消滅するのではなく、戦闘終了後もその場に物理的な重量とロールプレイ上の影響が残ります。

このシステムを実戦シナリオに取り入れることで、高い戦術的価値が生まれます：

- **負傷した味方の救出：** 組織的な小競り合いにおいて、支援役の味方は、敵の決闘者がとどめを刺す前に、負傷した仲間を防衛用の盾の壁や中庭の門の奥へと引き戻すことができます。
- **倒した敵の拘束・捕縛：** 勝利した侍や町奉行の役人は、倒れた相手を取り押さえ、正式な尋問、逮捕、または処罰へと引き渡すことが可能です。
- **人質交渉：** VIPやクランの首領を運ぶことで戦闘のテンポが一変し、武力衝突から繊細な交渉劇へとシフトするダイナミズムがコミュニティでも注目されています。

| 戦闘状態 | 発生条件 | 視覚的インジケーター | 実行可能な戦術的インタラクション |
| :--- | :--- | :--- | :--- |
| **体勢崩れ（Stagger）** | 重い一撃によるガードブレイク | バランスを崩すモーション、復帰遅延 | 直接的なダウン攻撃やガード不能技を受ける状態 |
| **行動不能（Downed）** | 体力ゲージがゼロになる | 膝をつく、地面に倒れ込む | 引きずる、担ぐ、蘇生する、逮捕するなどが可能 |
| **拘束 / 運搬中** | 行動不能状態の対象にインタラクト | 肩担ぎ、または引きずられる姿勢 | 運搬者の移動速度が低下；迎撃されるリスクあり |
| **完全復帰** | 応急手当の完了、またはタイマー経過 | 通常の構え状態へ復帰 | 移動および軽度の防御アクションが再開可能 |

倒れたプレイヤーを運ぶ際には、大幅な移動速度低下ペナルティが課せられることに注意してください。敵が射程内にいる状況で味方を引きずろうとすると、格好の標的になります。救出を試みる前に、まずは周囲の敵を排除するか、味方に援護射撃・牽制を依頼して連携を取ることが不可欠です。

## 高度な決闘戦術：相手の読みと誘導（エサ撒き）

経験豊富な強敵と対峙するハイステークスな **shogun s reign battle** では、高度な心理戦が要求されます。純粋な反射神経よりも、相手の行動を先読みすることの方がはるかに致命的です。あらゆる斬撃にはアニメーションフレームのコミット（硬直）が伴うため、相手にタイミングの悪い空振りを強要できれば、即座に致命的な反撃のチャンスが生まれます。

堅牢な防御を崩すために、実証済みの決闘テクニックを活用しましょう：

- **ウィフパニッシュ（空振り狩り）：** 相手の最大攻撃射程のわずか内側に踏み込み、直後に素早くバックステップします。相手の刃が空を切った瞬間、相手が硬直モーションに入っている間に踏み込み突きで反撃します。
- **ガードの条件付け（ガードコンディショニング）：** 相手のガードに対して、予測しやすい弱攻撃を2回当てます。相手がガードを固め続けることに慣れてきたら、3打目をガードブレイク性能の高い強攻撃やガード不能の押し出し技に切り替えます。
- **ディレイ・フェイント（攻撃遅延）：** 攻撃の振りかぶりモーションをキャンセルし、横ステップへ移行します。反射的なパリィに頼るプレイヤーは残像に向かって武器を振る形となり、側面を完全に晒して致命的な一撃を受けることになります。

```
攻撃側: [弱攻撃] ---> [弱攻撃] ---> [キャンセル/ディレイ] ---> [側面からの強攻撃]
防御側: [攻撃を防御] -> [攻撃を防御] -> [反射的なパリィ試行]  ---> [ガード粉砕・被弾]
```

自身の立ち回りから悪癖を排除するために、以下の戦術トラブルシューティング表を確認してください：

| よくある戦闘ミス | なぜ失敗するのか | 改善策・修正戦術 | 期待される結果 |
| :--- | :--- | :--- | :--- |
| **基本コンボの連打** | 単調なリズムになりパリィされやすくなる | 攻撃タイミングをあえてずらし、攻撃の高さや種類を変える | 相手がパリィのタイミングを誤り、ダメージを与えられる |
| **直線的な後退** | 前進突進攻撃やダッシュ斬りの格好の餌食になる | 相手の攻撃に対して斜め前〜横へサークル状に回り込む | 相手の前進モーメンタムを躱し、背後を取ることができる |
| **スタミナ管理の怠り** | ガードブレイクを起こすと一瞬で無防備になる | スタミナが25%になったら安全に間合いを取り回復する | 壊滅的なカウンターよろけを未然に防げる |
| **強攻撃への過度な依存** | 予備動作が長いため素早い弱攻撃に割り込まれる | 強攻撃は確定スタン時や側面・背後からの攻撃用に限定する | 攻撃を邪魔されることなく安定したダメージを維持できる |
| **追い詰められた時のパニック** | 壁際でドッジを連打して無駄にスタミナを消耗する | 足を止め、ガードを維持し、受け流しパリィの機会を狙う | 体勢をニュートラルに戻し、脱出ルートを確保できる |

これらの修正を徹底することで、厳かな中庭での果し合いであれ、予期せぬ路地裏での乱戦であれ、崩れることのない確実な立ち回りを身につけることができます。

## Shogun's Reignの戦闘に関するよくある質問（FAQ）

### 複数の敵を相手にする「shogun s reign battle」で安定して勝つにはどうすればよいですか？
数的不利な状況で勝利するには、徹底した位置取り（ポジショニング）が不可欠です。決して敵に囲まれてはいけません。常に集団の外側へと円を描くように回り込み、敵同士が重なってお互いの射線や攻撃角度を塞ぐように誘導してください。また、出入口、階段、橋などの狭いチョークポイントを利用し、集団戦を実質的な「1対1の連続戦」に持ち込むことが鉄則です。

### ガードが崩された後、最も効果的に復帰する方法は何ですか？
ガードブレイクが発生した場合の最優先事項は、即座の間合いの離脱です。攻撃キーを押すのは避けてください（復帰アニメーションが長引く原因になります）。代わりに、キャラクターの操作権が戻った瞬間に横への回避ステップまたは斜め後方へのステップを先行入力し、スタミナが回復するまでの間、敵の追撃から距離を取ってください。

### 鎧や服装の選択は、戦闘中の移動速度に影響しますか？
はい、影響します。重装のクラン甲冑は斬撃武器に対する大幅なダメージカットを提供しますが、コミュニティの検証報告によると、ダッシュ速度とスタミナ回復率がわずかに低下します。対して、軽装の伝統的な衣服は優れた敏捷性と迅速な回復速度を提供するため、回避やカウンターを重視するプレイスタイルに適しています。

### 「引きずり＆運搬」機能は、集団戦の勝敗にどのような影響を与えますか？
引きずり＆運搬機能により、組織化されたチームは倒れた味方に敵がとどめを刺す前に救出することができます。行動不能になった仲間を安全な後方へ引き戻して蘇生させることで、前線の圧力を維持し続け、消耗戦や衛生兵役との高度な戦術連携によって長期戦の戦局を覆すことが可能になります。
