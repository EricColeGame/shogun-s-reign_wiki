## Shogun's Reignの一族と江戸時代の身分制度を理解する

この封建時代ロールプレイ環境において、力とは単なる戦闘能力だけで測られるものではなく、社会的地位、家柄、そしてどの家に仕えているかによって決まります。一族（クラン）システムは江戸時代（*Edo jidai*）の厳格な身分制度を反映しており、誰と交流できるか、どのような衣服を着用できるか、公の場でどの武器の携行が許されるかを左右する明確な階層に社会を分割しています。

プレイヤーの体験談やコミュニティの報告によると、一族はサーバー全体のストーリー展開において強固な根幹を担っています。単なる戦闘ギルドとして機能するのではなく、**Shogun's Reignの一族**は名門の大家族、政治派閥、そして武力集団（従者団）として振る舞います。名声ある一族に加わることで、即座に庇護を受けられ、社会的威信や一族専用の屋敷・領地への立ち入り権を得られますが、同時にキャラクターは一族の長老や当主（大名／*Daimyo* や家系リーダー／*Kakei*）の命に従う義務を負うことになります。

家中における階層構造は概ね歴史上の身分序列を反映しており、公開ロールプレイセッション中に明確な指揮系統を生み出します。

| 一族内の階級 | 役職 / 役割 | 主な責務 | 許可される装備・ステータス |
| :--- | :--- | :--- | :--- |
| **当主（Clan Head）** | 大名（*Daimyo*） / 頭（*Kashira*） | 家中の統治、外交、一族評定の主催 | 当世具足（甲冑一式）、儀礼用刀、家紋（*kamon*） |
| **重臣（High Retainer）** | 家老（*Karō*） / 旗本（*Hatamoto*） | 大名への進言、管区の巡邏指揮、治安維持 | 打刀、脇差、上質な絹の羽織 |
| **一族の武士（Clan Samurai）** | 武士（*Bushi*） / 郷士（*Goshi*） | 武力行使、警護任務、名誉ある決闘の遂行 | 打刀、一族支給の標準的な防具または着物 |
| **見習い・小姓（Apprentice）** | 小姓（*Koshō*） / 足軽（*Ashigaru*） | 門番・歩哨、重臣の身の回りのお世話、後方支援 | 脇差または槍（*yari*）、質素な旅装束 |
| **使用人・奉公人（Servant / Dependent）** | 町人（*Chonin*） / 奉公人（*Hōnin*） | 屋敷の維持管理、職人仕事、芸能、雑務 | 非致死性道具、一般的な木綿の平服 |

許可なく己の身分を越えた行動をとること（例えば、評定の席で見習いが家老（*Karō*）の言葉を遮って発言するなど）は、懲戒ロールプレイ、公の場での降格、あるいは勘当・除籍につながることが少なくありません。

## Shogun's Reignの主要な一族：類型、家系、専門分野

個々のプレイヤーによって新たな家系が立ち上げられることも多いですが、コミュニティを支えているのは歴史あるいくつかの類型と名門家系です。プレイヤー層において、主要な**Shogun's Reignの一族**は概ね「武力・防衛」「行政・公家/士族」「文化・芸能振興」という3つの柱に分かれています。

コミュニティの報告によると、上杉（Uesugi）、三浦（Miura）、井上（Inoue）といった名門家系は、独自のビジュアルアイデンティティと行動規範を確立しています。以下は、活動中のサーバーで見られる主要な一族の専門分野の内訳です。

| 一族の類型 | ロールプレイの焦点 | 象徴的な外観・装い | 主な活動内容 |
| :--- | :--- | :--- | :--- |
| **武家（Buke）** | 領地防衛、市中巡邏、御前試合・武芸大会 | 漆塗りの甲冑、濃藍、深紅、家紋 | 城門・関所の警備、街中の騒乱鎮圧、要人警護 |
| **公家・上層士族（Kuge / Shizoku）** | 行政・法執行、朝廷・幕府内の政治工作、外交の宴席 | 華麗な絹織の着物、純白や金色の装飾、扇子 | 茶会の主催、一族間協定の仲介、裁判・裁定 |
| **豪商・職人家（Merchant & Artisan Houses）** | 商業、市場支配、物資の交易 | アースカラーの羽織、大福帳（帳簿）、銭袋 | 茶屋の経営、反物・織物の取引、武家への資金提供 |
| **文化・芸能座（Cultural & Entertainer Guilds）** | 芸術の鍛錬、伝統芸能の披露 | 繊細な簪（*kanzashi*）、優美な舞妓装束、三味線 | 季節の祭礼での演舞、花街・遊郭エリアでの催し物 |

名門家系を選んだり入門の選考を受けたりする際は、キャラクターコードの要件を確認してください。多くの家系では、キャラクターの体型プロポーション、肌の色合い、指定の髪型を統一するために専用のセーブファイルコードを配布しており、すべての構成員がその家の格式に相応しい外見を保てるようにしています。

## 一族への加入方法、昇進、システムの活用法

名声ある**Shogun's Reignの一族**に加入するには、単に参加申請を送るだけでは不十分です。本作は深く没入感のあるロールプレイを重視しているため、ほとんどの一族はコミュニティのDiscordハブを活用しつつ、ゲーム内キャラクターとしての審査（*IC*：In-Character選考）を実施しています。

```
平民 / 放浪の浪人
          │
          ▼
   初謁見（IC審査・面談）
          │
          ▼
  見習い / 足軽階級
          │
          ▼
 忠誠の誓い＆家紋の授与
          │
          ▼
    誓詞を立てた家臣（武士）
```

活動的な家中に無事迎え入れられるには、以下の標準的な入門手順を踏みます。

1. **本格的なキャラクター設定の構築:** 江戸時代という世界観に即したオリジナルキャラクター（*OC*）を作成します。時代錯誤な肩書や現代風の言葉遣いは避けましょう。
2. **カスタムセーブコードの適用:** 多くのプレイヤーは、コミュニティで共有されているキャラクタープリセットを利用して、時代考証に合った髪型、顔立ち、衣服を揃えています。新規加入者として応募する場合は、質素な外見を維持しましょう。
3. **ゲーム内での謁見（IC面会）を求める:** 礼儀正しく一族の屋敷を訪ねます。中庭に無断で押し入るのではなく、門の前で一礼し、門番に取り次ぎを頼みましょう。
4. **試用期間の任務をこなす:** 通常、最初は実績のない使用人や足軽（*ashigaru*）として始まります。警備の当番を務め、使い走りをこなし、礼節あるロールプレイマナーを示しましょう。
5. **一族の誓いを立てる:** 正式に認められると、家名を名乗る権利と一族の公式な羽織や装束を着用する権利が与えられます。

出世の道は忠誠心と活動の継続性にかかっています。以下の表は、無名の放浪者から家中の重臣へと昇進していく一般的なプロセスを示しています。

| 昇進段階 | 必要とされる功績・行動 | 標準的な期間 | 解放される主なシステム・権限 |
| :--- | :--- | :--- | :--- |
| **門下生 / 志望者（Initiate / Applicant）** | 違反のない素行履歴、IC面接の合格 | 1〜3日 | 屋敷の外郭エリアへの立ち入り権 |
| **若手家臣（Junior Retainer）** | 担当区の巡邏、一族評定への出席 | 1〜2週間 | 一族支給の武具の帯刀・携行権 |
| **古参武士（Senior Bushi）** | 公認決闘での勝利、新人の育成・指導 | 3〜5週間 | 現場での指揮命令権 |
| **家老・長老（House Elder）** | 他家との外交交渉、催事の主催、大名からの任命 | 2ヶ月以上 | 一族の新規採用管理および金庫・資金管理 |

## 一族の政治抗争とロールプレイのエチケット

対立する**Shogun's Reignの一族**同士の外交的摩擦は、本作におけるドラマチックな展開の最大の原動力です。市場地区の利権を巡る緊迫した交渉から果たし場での正式な決闘まで、悪質なトラブルを防ぐためにすべてのやり取りはコミュニティ基準に従う必要があります。

プレイヤーに親しまれている特徴的なインタラクティブ機能の一つに、行動不能になったキャラクターを引きずったり担いだりできる物理インタラクションシステムがあります。所属のない浪人や敵方の家臣が一族の名誉を傷つけた場合、護衛は「引きずり・担ぎ」機能を使って身柄を拘束し、単なる即時リスポーンの繰り返しではなく、正式な吟味（裁判）や公の場での処罰ロールプレイへと発展させます。

一族間の対立において質の高いロールプレイを維持するために、以下の行動規範を守りましょう。

| 遭遇シーン | 推奨される行動 | 禁止行為 | 解決方法 |
| :--- | :--- | :--- | :--- |
| **関所・境界でのトラブル** | 身元の確認、通行手形の検問 | 対話なしの即時攻撃 | 言葉による事態鎮静化、または奉行所への連行 |
| **名誉の毀損・侮辱** | 正式な決闘（居合術／*Iaijutsu*）の申し入れ | 無差別な集団襲撃（*RDM*） | 立会人（審判）のもとでの1対1の果たし合い |
| **縄張りの巡邏** | 隊列を組んでの行進、町人市場の監視 | 従順な商人への理不尽な嫌がらせ | 過料（罰金）の徴収または一族公式の警告状 |
| **和睦・親睦の宴** | 入口での刀の預託、進物の交換、歓談 | 奥座敷・茶室内での抜刀 | 当主同士の署名による和議・協定締結 |

こうした暗黙のルールを理解しておくことで、[Roblox platform](https://www.roblox.com) コミュニティに関わるすべての参加者が、円滑で刺激的、かつ互いに敬意を払ったロールプレイを楽しむことができます。

## 新たな一族の創設と運営

既存の大名に仕えることを望まないなら、独立した一家を立ち上げることも可能です。新しい**Shogun's Reignの一族**を創設するには、綿密な組織作り、明確なキャラクターガイドライン、そして高いアクティブ率を維持できる献身的な中核メンバーが必要です。

公に一族の立ち上げを宣言する前に、初期の数週間を生き残るために以下の運営チェックリストを確認してください。

| 組織化フェーズ | 主要な作成物・決定事項 | 推奨ツール |
| :--- | :--- | :--- |
| **1. 設定と家系（Lore & Lineage）** | 一族の背景設定、家紋（*mon*）、結党の趣意書 | コミュニティドキュメント、歴史資料 |
| **2. 装束規程・コード（Dress Code & Codes）** | 認可された着物ID、OCセーブコード、武器規則 | ゲーム内キャラクターエディタ、衣装一覧表 |
| **3. 指揮系統（Command Structure）** | 大名、家老、部隊長の任命 | ロールプレイ名簿スプレッドシート |
| **4. 屋敷と縄張り（Compound & Territory）** | 未占有地区や集会用屋敷の選定 | サーバー内のロケーション調査 |
| **5. 外交方針（Diplomatic Outlines）** | 他家との平和条約・通商協定の草案作成 | ロールプレイ用の外交書状（IC書状） |

一族の運営に成功しているリーダーたちは、プレイヤーの定着に最も力を注いでいます。稽古（訓練セッション）、茶屋での夜話会、季節の祭りなど、定期的な内輪の催し物を開催することで、サーバーが落ち着いている時間帯でも家臣たちの意欲を維持させることができます。

## Shogun's Reignの一族に関するよくある質問

### Shogun's Reignの一族に加入するメリットは何ですか？
一族に加わることで、組織的な集団ロールプレイへの参加、専用屋敷への出入り、体系化された出世制度、野良プレイヤーからの保護といった恩恵を受けられます。また、名門家系の一員となることでキャラクターの物語的背景が瞬時に確立され、サーバーの大規模イベントや外交評定に格段に参加しやすくなります。

### 一族から追放されたり破門されたりすることはありますか？
はい。一族内部の掟を破る、上級家臣に不敬を働く、同盟勢力に対して独断で暴力行為に及ぶなどの行動は、不名誉な除名（改易・破門／*Kaidan*）や追放処分につながります。追放されたプレイヤーは、名誉を回復するか他家に仕官するまで、主を持たぬ「浪人（*ronin*）」としてロールプレイを続けることが一般的です。

### 有名なShogun's Reignの一族に入るにはRobuxが必要ですか？
いいえ、必要ありません。カスタム着物テクスチャやヘアパス、各種ゲームパスはキャラクターの見た目のディテールを高めることができますが、評判の高い**Shogun's Reignの一族**の多くは、課金額ではなく、純粋にロールプレイの技量、キャラクターの作り込み、振る舞いの成熟度によって加入希望者を判断します。

### 敵対する侍同士の一族間決闘はどのように行われますか？
公認された果たし合いには、双方の合意と公平な立会人（審判）が必要です。家臣同士はサーバーの戦闘ガイドラインを厳格に遵守し、カウントダウンに合わせて抜刀します。敗者は、公の場での謝罪、一族の縄張り譲渡、あるいは一時的な負傷療養ロールプレイなどの結果を受け入れます。
