## 封建社会の身分序列：Shogun's Reignの領主とは？

歴史ロールプレイにおいて、階級は単なる見た目の肩書にとどまらず、他のプレイヤーが自身のキャラクターにどのように接するかを直接左右します。支配階級は複数の序列で構成されており、地方の荘園代官から幕府の評定で直接謁見を許される大名まで多岐にわたります。

この厳格な身分制度の中で自分の貴族キャラクターがどこに位置づけられるのかを把握することは極めて重要です。プレイヤーの経験上、定められた身分を超えて権力を誇示しようとすると、不名誉を被ったり、決闘を申し込まれたり、コミュニティの町奉行によって追放処分を受けることが珍しくありません。

| 封建的階級 | 和名・役職 | 主なロールプレイ責務 | 権限レベル |
| :--- | :--- | :--- | :--- |
| **Provincial Daimyo（国主大名）** | 大名 (*Daimyō*) | 一族の統率、領地からの徴税、評定・裁きの主宰 | 領内における絶対的権限 |
| **Castle Magistrate（城代）** | 城代 (*Jōdai*) | 城郭の管理、守備隊指揮官の統括、交易の管理 | 高い地域統括権 |
| **Clan Elder / Senior Retainer（家老）** | 家老 (*Karō*) | 大名への補佐、外交交渉、財政運営 | 実質的な行政執行権 |
| **Hatamoto (Bannerman)（直参旗本）** | 旗本 (*Hatamoto*) | 将軍直属の家臣、精鋭親衛隊、司法判断・仲裁 | 幕府直轄の公的管轄権 |

Shogun's Reignの領主が一般の武士や町人と決定的に異なる点は、非言語的なモーションや周囲の恭順の姿勢によって自然と敬意を集める点にあります。町人が生業に精を出したり芸妓・舞妓として芸を披露したりしている間、領主は地域の交易の流れを差配し、管轄区域の治安維持に目を光らせてセッションを過ごします。

## 一族の統率と名門の血統

貴族としての地位は、個人の功績だけで成立することは稀であり、家紋や歴史ある一族の血統と密接に結びついています。組織化されたロールプレイセッションでは、有力な家柄がマップ上の特定の屋敷、茶庭、関所などを実効支配しています。

領主を目指すプレイヤーにとって、公認の一族に加わるか、正当な分家を興すことは、政治的対立が生じた際に即座に後ろ盾を得る有効な手段です。各サーバーの派閥は定期的に城郭に集まり、同盟を結んだり領地境の争いを調停したりしています。

## ロールプレイの仕様：領主の権能・礼法・システム

貴族のロールプレイは、華麗な絹の着物を着て優雅に歩くだけでは務まりません。家臣を従え、法を犯した者を処罰するためには、ゲーム内のインタラクション機能を能動的に活用する必要があります。

本作を特徴づけるシステムのひとつが物理インタラクションです。プレイヤーの報告によると、「運搬・連行（drag-and-carry）」機能により、高位の人物やその護衛は治安を乱す者を拘束したり、小競り合いで負傷した味方を搬送したり、罪人を直接牢屋へと連行したりすることが可能です。

```
[貴族ロールプレイにおける正式な入場手順]
1. 家臣が領主の到着を触れ回り、街道を払い清める。
2. 領主が進み出て、規定の身分間距離を保つ。
3. 下位プレイヤー（町人、舞妓、浪人など）は平伏の礼（土下座／お辞儀）を行う。
4. 護衛は領主の背後に回って警戒陣形をとる。
5. 領主への会話は厳格な敬語（Keigo）でのみ開始される。
```

本格的な時代劇の雰囲気を維持するため、貴族キャラクターは公の場に出る際、以下の厳格な礼法に従うことが求められます。

| 場面 | 貴族に求められる立ち振る舞い | 町人・家臣側の反応 | 礼法違反時のRP上の結果 |
| :--- | :--- | :--- | :--- |
| **大名行列・巡察** | 堂々とした歩調、最低1名の護衛同伴 | 街道中央を譲り、視線を落とす | 護衛武士による即座の詰問・斬捨 |
| **公式な謁見・評定** | 一段高い上段の間に着座、沈黙を守り威厳を保つ | 板の間に平伏、促された時のみ発言 | 侮辱罪の適用、広間からの強制退去 |
| **紛争の仲裁・裁定** | 家法に基づいた公平無私な裁決 | 下問があるまで証言を控える | 一族の面目失墜、正式な果し合いへ発展 |
| **領内視察** | 工匠の店を検分、献上品を受け取る | 目を直接合わせずに品物を差し出す | 営業差し止め、または課税の強化 |

パブリックサーバーでプレイする際は、懲罰や規律を目的としたロールプレイが全参加者にとって建設的で楽しいものとなるよう、[Roblox コミュニティ基準](https://en.help.roblox.com/hc/en-us/articles/203313410-Roblox-Community-Standards)に定められた行動規範を必ず順守してください。

## 領主キャラクターの作成とカスタマイズ（OC衣装と美学）

高貴な身分は視覚的にも表現されなければなりません。コミュニティのクリエイターたちはSNS上でカスタムコードやセーブデータを共有しており、本格的な歴史衣装を再現できるようになっています。リアルなShogun's Reignの領主を作成するには、史実に基づいた美意識と個性的なディテールを両立させることが鍵となります。

領主の外見は、格式高い裃（かみしも）、特徴的な被り物、家紋、そして格式ある儀礼刀剣によって形作られます。簡素な陣笠と粗布の小袖を身につける足軽とは異なり、貴族の装束には深みのある色彩、精緻な刺繍、そして豪奢な刀装具が用いられます。

| カスタマイズ部位 | 推奨される貴族の装束 | 好まれる色合い | 演出意図・美学 |
| :--- | :--- | :--- | :--- |
| **上着（肩衣/Kataginu）** | 両肩が張った袖なしの上衣 | 藍色、深紫、墨色、深紅 | 威風堂々とした立ち姿と威厳の強調 |
| **袴（Hakama）** | 裾を長く引く長袴（Nagabakama） | 上衣に合わせた同系色、または落ち着いた鼠色 | 屋内での高貴な身分と優雅さの誇示 |
| **髪型・被り物** | 端正な丁髷（Chonmage）または烏帽子 | 漆黒、艶やかで手入れの行き届いた質感 | 洗練された身嗜みと家柄の良さを表現 |
| **腰回り・帯** | 大小二本差し（揃いの打刀と脇差） | 金象嵌の鞘、正絹の下げ緒 | 武家特権である帯刀権の誇示 |
| **手持ちの小道具** | 軍配（Gunbai）または扇子（Sensu） | 金箔押し、漆塗り骨、家紋入り和紙 | 大声を上げずに合図や指示を送るため |

プレイヤー間では、歴史上の偉人を再現したり独自のオリジナルキャラクター（OC）を生み出すために、コミュニティハブを通じて頻繁にセーブコードが交換されています。領主をデザインする際は、ファンタジー風の過剰なアクセサリーで着飾りすぎないよう注意しましょう。派手すぎるエフェクトよりも、史実に基づいた洗練された細部こそが、何よりも確かな威厳を漂わせます。

## 攻略の道筋：領主として頭角を現すためのステップ

貴族の地位は一朝一夕にして得られるものではありません。多くのサーバーは実力主義のロールプレイを採用しており、プレイヤーはまず家臣、足軽、あるいは野良の浪人として身を起こし、既存の派閥当主から認められて一門へと引き上げられることになります。

コミュニティの知見によると、名君として成功した領主の多くは、新規プレイヤーの育成、計画的な見回り任務の編成、茶屋での風雅な茶会の主催などに多くの時間を費やしています。サーバーの常連プレイヤーと確固たる信頼関係を築くことこそが、世襲の家柄を手に入れる最も確実な道です。

| 段階 | 注力分野 | 主な目標 | 達成すべきマイルストーン |
| :--- | :--- | :--- | :--- |
| **第1段階：近習・家臣** | 武芸の鍛錬 | 屋敷門の警備、パリィ（受け流し）の習熟、上役への奉公 | 公認一族のDiscordに参加、決闘で5勝を挙げる |
| **第2段階：組頭・士官** | 部隊指揮 | 街道見回りの指揮、荒くれ浪人の鎮圧、兵站管理 | 一族の家老から賞賛を受け、正絹の袴を賜る |
| **第3段階：旗本・直参** | 行政実務 | 茶会の主催、商人間の取引紛争の調停 | 旗本昇格、一族の家紋使用を認可される |
| **第4段階：領主・大名** | 領国統治 | 領内裁判の開廷、徴税管理、一族間外交の主導 | サーバー全体の合意により正式に大名へ就任 |

単なる戦闘力よりも、物語としての深み（ナラティブ）を重視しましょう。領主として誇りを守るための剣術は心得ておくべきですが、真の力は発する言葉、従える家臣団、そして自らの背後に控えるプレイヤーたちの揺るぎない忠誠心の中にこそ宿るのです。

## Shogun's Reignの領主に関するよくある質問（FAQ）

### 領主の日々のロールプレイにおける職務は何ですか？
領主は一族間の外交、担当地区の統治、正式な評定・謁見の主宰、身分の低いキャラクター間の法的な紛争調停などを行います。また、祭礼の主催や、配下の侍が街の治安を乱していないかの監督も担います。

### 始めたばかりのプレイヤーでもすぐに領主になれますか？
セーブコードやマーケットプレイスのアイテムを使って、見た目を貴族のように着飾ることは誰でも可能です。しかし、真の影響力を行使するにはサーバー内の一族組織から認められる必要があります。他のプレイヤーからの人望を集め、一族の長老から正式な役職を拝命することが、指導者として機能するための必須条件です。

### 「運搬・連行（drag-and-carry）」機能とは何ですか？なぜ領主が使うのですか？
運搬・連行機能とは、行動不能になったプレイヤー、捕縛した罪人、または負傷したアバターを物理的に担ぎ上げて移動させることができる仕組みです。領主やその護衛は、治安を乱す者を番所や牢屋へ連行したり、危険な戦闘地帯から要人を安全に救出する際によくこの機能を使用します。

### 周囲から尊敬される領主であり続けるにはどうすればよいですか？
一貫して礼儀作法を守り、家臣を公平に扱い、サーバーのロールプレイ規範を順守し、理由なき辻斬り（RDK：Random Deathmatching）を行わないことが重要です。機知に富んだ質の高い対話を心がけることで、コミュニティ内で信頼される指導者としての立場を確固たるものにできます。
