## 基本移動とナビゲーションのキーバインド

茶屋、山道、城の境内をスムーズに行き来するには、基本的なアバター操作の土台を固めておく必要があります。Shogun's Reignの標準操作に慣れ親しむことで、アバターの歩調を正確にコントロールし、礼儀正しい足取りと素早い撤退をシームレスに切り替えられるようになります。

本格的な歴史ロールプレイにおいて、移動速度は非常に重要な意味を持ちます。常に全力疾走していると、周囲のロールプレイヤーや治安関係者から不審者や無作法者とみなされる可能性があるため、歩きへの切り替えや構えの調整は必須のテクニックとなります。

| アクション | メインキー（PCキーボード） | サブ / マウス | 機能 / 説明 |
| :--- | :--- | :--- | :--- |
| **前進** | `W` | 上矢印キー | ダッシュ状態に応じて前方に歩行または走行 |
| **後退** | `S` | 下矢印キー | 後退、または防御姿勢で後ろにステップ |
| **左移動（平行移動）** | `A` | 左矢印キー | カメラの向きを変えずに左へサイドステップ |

### カメラ視点と没入感の設定

緊迫したロールプレイ環境では、周囲の状況を常に把握しておくことが極めて重要です。三人称視点は、市場での取引や混雑した人混みを移動する際に優れた空間把握力を発揮します。一方、マウスホイールを使って一人称視点に切り替えると、楽器の演奏、茶の湯の儀式、将軍の前での厳かな謁見などにおいて、圧倒的な没入感を得ることができます。

## インタラクション機能：引きずり・担ぎ・RPアクション

ソーシャルロールプレイゲームの醍醐味は、プレイヤー同士の自発的なインタラクションにあります。このRP環境において、Shogun's Reign独自の操作体系は、村人への接し方、負傷した仲間の救助、あるいは治安を乱す無法者の制圧方法を司っています。

コミュニティの報告やプレイヤーの体験談によると、本作屈指の注目機能がこの物理的なキャラクター運搬システムです。ダウンしたアバターや同意した他プレイヤーを拘束・引きずり・担ぎ上げる機能により、救命劇から公の場での捕縛まで、ドラマチックな物語の展開が生まれます。

| インタラクション操作 | デフォルトPCキー | 対象の条件 | ゲームプレイへの影響 |
| :--- | :--- | :--- | :--- |
| **調べる / インタラクト** | `E` | 近くのオブジェクトまたはプレイヤー | 扉の開閉、畳に座る、各種インタラクト |
| **ダウン者の引きずり** | `V` または状況に応じた `E` | ダウン中 / 負傷したプレイヤー | 襟首を掴んで地面の上を引きずる |
| **肩に担ぐ** | `B` またはラジアルメニュー | ダウン中または同意したプレイヤー | 相手を肩の上に担ぎ上げて運ぶ |
| **降ろす / 手放す** | `V` または `スペースバー` | 誰かを運搬中の状態 | 運んでいる相手を安全に地面へ降ろす |
| **正座 / お辞儀（礼）** | `K` またはチャットで `/bow` | 平らな床・地面のスペース | 貴族や当主に対して敬意を表す |
| **エモートラジアルメニュー** | `G` または `.`（ピリオド） | なし | 時代劇に即した所作ホイールを開く |
| **RPバイオ / 詳細確認** | `H` またはマウスクリック | 他プレイヤーにカーソルを合わせる | 相手の役職、所属勢力、背景設定を表示 |

### 引きずり・担ぎシステムの活用法

運搬システムには、地形の高低差や障害物の配置に反応するリアルタイム物理演算が導入されています。ターゲットを引きずっている最中は、急な階段を駆け上がったり、狭い障子戸を一気に通り抜けようとしたりするのは避けてください。急激な物理判定の衝突により、手が離れてしまったりキャラクターの位置が不自然に飛んでしまったりすることがあります。安全な場所や牢屋へ連行する際は、常に前を向き、落ち着いたペースを保つのがコツです。

## 戦闘・装備・カスタマイズの操作

文化やコミュニティ体験に重きが置かれている本作ですが、敵対する一族や野盗との小競り合いは避けられません。緊張が高まり果たし合いに発展した際、Shogun's Reignの素早い戦闘操作が生死の分かれ目を決定づけます。

戦闘に入る前には、刀を鞘から抜く動作（抜刀）が必要です。これは当時の作法を忠実に再現しているだけでなく、近くの見張り番に対して敵対の意志を伝える合図にもなります。

| 戦闘＆アイテム操作 | キーバインド（PC） | 必要な状態 | 戦術的・RP的な活用法 |
| :--- | :--- | :--- | :--- |
| **抜刀 / 納刀** | `R` または数字スロット `1` | 素手状態 | 戦闘態勢への移行、または武器を収めて警戒を解く |
| **通常攻撃（弱攻撃）** | `マウス左ボタン` | 武器を構えた状態 | 素早い連続技を繰り出すための鋭い斬撃 |
| **強攻撃 / フェイント** | `右クリック` + `左クリック` または `F` | 武器を構えた状態 | 硬直時間と引き換えに相手のガードを崩す |
| **パリィ / 防御の構え** | `F`（長押し） | 武器を構えた状態 | 正しいタイミングで敵の斬撃を弾き返す |
| **サイドステップ / 回避** | `Q` + 移動方向キー | 戦闘スタンス中 | 広範囲の薙ぎ払いやすれ違いの突きを回避 |

### 衣装とキャラクターコードの管理

キャラクターの見た目のカスタマイズは、本作の育成・自己表現において大きなウェイトを占めています。多くのプレイヤーがキャラクターコードを集め、侍、商人、芸者といった多様な身分にふさわしい華やかな着物、髪型、装飾品を着替えて楽しんでいます。

カスタマイズ用の衣装箪笥は、画面上の専用UIアイコンを押すか、町屋地区にある試着鏡に近づくことで利用できます。衣装コードを入力枠に直接貼り付けるだけで、進行中の物語や場面に合わせて見た目を瞬時に変更することが可能です。

## 流れるようなロールプレイと戦闘最適化のための上級テクニック

操作設定を細かく調整しておくことで、緊迫したRPの場面や激しい乱戦での致命的な入力遅延を防ぐことができます。熟練プレイヤーたちが実践している実用的な設定とコツをご紹介します：

*   **シフトロックとダッシュのキーを分ける：** お使いの環境でシフトロックとダッシュが同じキーに割り当てられている場合は、設定メニューでシフトロックの割り当てを変更し、逃走中などに意図せずカメラが固定されてしまう事故を防ぎましょう。
*   **チャットコマンドで素早くエモートを発動：** 厳格な評定や謁見の席でエモートホイールを広げる代わりに、チャット欄に `/e bow`、`/e sit`、`/e kneel` などのスラッシュコマンドを直接打ち込むことで、流れるような美しい所作を行えます。
*   **抜刀アニメーションの隙に注意：** 武器を抜く際には一定の硬直モーションが存在します。相手がすでに刀を振っている最中に抜刀キー（`R`）を押してはいけません。刀を完全に構えるまではパリィを行うことができません。
*   **スタミナの温存を意識する：** 走り続けるとスタミナゲージが枯渇し、息切れを起こして一時的に無防備な状態となります。屋内にいるときは歩き切り替え（`Ctrl`）を常用し、万が一の事態に備えてスタミナを満タンに保ちましょう。

| ロールプレイの場面 | 推奨キーシーケンス | 戦術的・作法上の利点 |
| :--- | :--- | :--- |
| **一族の重鎮への拝謁** | `Ctrl`（歩き） -> 停止 -> `K`（正座・平伏） | 走る無礼を避け、格式ある忠誠を示す |
| **乱暴者の取り押さえ** | `F`（斬撃をパリィ） -> 打ち倒す -> `V`（引きずり） | 逃げ回らせることなく秩序正しく鎮圧する |
| **茶席でのマナー** | 持ち物を収める（`Z`） -> 座布団で `E` -> エモート | 平和的な席で誤って武器を抜いてしまう事故を防止 |
| **間合いを取る離脱** | `Q` + `S`（後方ステップ） -> `左Shift`（ダッシュ） | 相手の猛攻から素早く間合いを外して退避 |

## Shogun's Reignの操作に関するよくある質問（FAQ）

### 他のプレイヤーを担いだり引きずったりするにはどうすればいいですか？
ダウンしているプレイヤーや倒れているアバターに近づき、`V`キーを押すと地面を引きずり、`B`キー（または`E`のインタラクションメニューから選択）を押すと肩の上に担ぎ上げることができます。相手を降ろしたい場合は、もう一度同じキーを押すか、ジャンプしてください。

### PC版でキーバインドを変更することはできますか？
インタラクトの`E`や抜刀の`R`など、固有システムのキーの多くはゲーム独自のUIに固定されていますが、移動やカメラ操作といった一般的なキー設定は、`Escape`キーを押して開くRoblox標準の設定メニューから調整可能です。

### 刀を抜く（抜刀）・収める（納刀）の操作キーは何ですか？
刀や武器を抜くには、`R`キーを押すか、対応するホットバースロットの数字キー（通常は`1`）を押します。もう一度`R`キーを押すか、アイテム解除キー（`Z`またはバッククォート）を押すと、刀を安全に鞘へと収めます。

### キャラクターカスタマイズや衣装コードの入力画面はどこから開きますか？
画面の左端または上部にある鏡やハンガーのアイコンをクリックするか、町の着替え部屋で`M`キーを押すことで衣装カスタマイズ画面を開くことができます。そこにあるテキスト入力欄に保存コードを貼り付けることで、コミュニティが作成した着物やアクセサリーのコーディネートを一瞬で適用できます。
