## Shogun's Reignの基本キー配置と移動操作

戦国時代の戦場を効率よく駆け巡るには、俊敏で正確なキャラクター操作が欠かせません。刀を抜く前に、周囲の環境との相互作用、スタミナ管理、そしてカメラアングルの調整方法を把握しておく必要があります。

プレイヤーの経験則として、視点をターゲットにロックしつつ起伏の多い地形を滑らかに動き回ることが、即座に戦術的優位を生み出します。操作系は標準的なPC配置をベースとしていますが、特定の入力によってダッシュ、障害物の乗り越え、細い橋の歩行などの挙動が変化します。

| キー / 入力 | アクション | ゲーム内機能 | 戦術メモ |
| :--- | :--- | :--- | :--- |
| **W, A, S, D** | 方向移動 | 前後左右に移動 | ダッシュと組み合わせて素早い位置取りが可能 |
| **スペースバー** | ジャンプ / 乗り越え | 低い障害物を跳び越え、高所へ移動 | 連続で使用すると少量のスタミナを消費 |
| **左Shift** | ダッシュ | 高速走りの切り替えまたは長押し | 長時間の使用でスタミナゲージを継続消費 |
| **Q** | ダッシュ回避 / ステップ | 敵の攻撃を素早く回避する短いステップ | タイミングが合えばわずかな無敵時間が発生 |
| **左Ctrl** | しゃがみ / ステルス | 姿勢を低くして足音を軽減 | 奇襲攻撃や低い攻撃の回避に有効 |
| **C** | カメラロック / フリーカメラ | 視点を固定、またはカメラロックを解除 | 敵の刃を常に視界に捉え続けるために不可欠 |
| **左Alt** | 歩き切り替え | 通常のジョギングと慎重な歩行を切り替え | 崖際や足場の悪い場所での精密な移動に便利 |

移動アクションはスタミナに直結しています。スタミナ残量を気にせずにステップやダッシュジャンプを連発すると、ガードブレイクの隙を晒すことになります。危険なエリアに入る前に、間合いの外へ離脱する動作が無意識に繰り出せるようになるまで、標準のキー配置で回避の練習を重ねておきましょう。

## 戦闘操作と武器アクションのキー配置

戦闘システムは一瞬の判断と正確さを要求し、クリックのタイミングを誤れば壊滅的な反撃を浴びることになります。命懸けの侍の果たし合いにおいて、攻撃側のキー配置は攻撃のテンポ、パリィの成否、そして構えの選択を左右します。

一振り一振りの攻防は、敵の防御を探る素早い「弱攻撃」と、ガードを粉砕して体勢を崩す強力な「強攻撃」のバランスの上に成り立っています。以下の表は、戦闘および主要なインタラクトに関する必須ホットキーの一覧です。

| キー / 入力 | 戦闘アクション | システム解説 | 実戦のコツ |
| :--- | :--- | :--- | :--- |
| **マウス左ボタン（LMB）** | 弱攻撃 | スタミナ消費が少ない素早い斬撃 | 敵の攻撃予備動作の阻止やコンボの始動に最適 |
| **マウス右ボタン（RMB）** | ガード / パリィ | 刀を構えて物理攻撃を防御 | 着弾直前に合わせると「ジャストパリィ」が発動 |
| **F** | 強攻撃 / ガードブレイク | 隙は大きいが通常ガードを崩す大ダメージ攻撃 | 長押しで溜めることで威力がさらに増加 |
| **R** | フェイント / キャンセル | 攻撃の振りかぶりモーションを中断 | 相手に空振りのパリィを出させて隙を作る |
| **E** | インタラクト / とどめ | 扉の開閉、宝箱の回収、体勢崩れ敵の処刑 | 敵がよろめき状態になったら素早く押す |
| **X** | 納刀 / 抜刀 | 装備中の武器を収める・抜く | 非戦闘エリア（安全地帯）では納刀が必須な場合あり |
| **1, 2, 3, 4** | 武器 / アイテムスロット | メイン武器、サブ武器、道具の切り替え | 戦闘中に切り替えて攻撃の間合いを変化させる |
| **G** | 体勢回復 / 精神集中 | 気を集中させて防御ゲージ（体勢値）を急速回復 | 敵の間合いから安全に離れている時のみ使用 |

**RMB**を長押しする通常のガードと、タイミングよく合わせるパリィの違いを理解することが極めて重要です。ガードを押し続けると連続攻撃によって体勢値が削られ、最終的にはスタン（気絶）状態に陥ります。一方、絶妙なタイミングのパリィは攻撃を完全に弾き、相手をよろめかせて弱攻撃による確実な反撃チャンスを生み出します。

## デフォルト操作で行う応用テクニックとコンボ

基本操作を把握したら、これらのアクションを連携させることで、守りを固めた相手を崩すことができるようになります。上級プレイヤーはキー配置を巧みに操り、攻撃を流れるように繋いで相手の防御タイミングを狂わせます。

フェイントは、対人戦において最も強力な戦術の1つです。**LMB**または**F**を押した直後に素早く**R**を押すことで、振りかぶり動作の途中で攻撃を中断できます。反射的にパリィを出した相手には硬直時間が発生するため、無防備な状態へ追撃を叩き込むことが可能です。

| コンボ名 | 入力手順 | 期待される効果 | 最適な使用場面 |
| :--- | :--- | :--- | :--- |
| **ベイト＆スラッシュ** | LMB &rarr; R &rarr; LMB | パリィを誘発させて即座に隙へ攻撃 | パリィを狙ってくる防御重視の相手に対して有効 |
| **ガードブレイカー** | ダッシュ + LMB &rarr; F（長押し） | 一気に間合いを詰め、ガードを強制突破 | 刀や盾の後ろに引きこもる相手に対して有効 |
| **回避＆反撃** | Q（側面）&rarr; RMB（パリィ）&rarr; LMB | 初撃をステップでかわし、連撃を弾いて反撃 | 弱攻撃を連打してくるアグレッシブな相手に対して有効 |
| **よろめき処刑** | F（崩し）&rarr; E（処刑） | 残りの体勢値を削りきり、致命の一撃を実行 | スタミナゲージが枯渇しかけている最優先ターゲット |

コミュニティからも指摘されている通り、入力先行（インプットバッファ）の仕組みに注意が必要です。キーを連打すると次の動作がキューに溜まってしまいます。相手が強攻撃を繰り出そうとしている時に**LMB**を素早く3回連打してしまうと、入力キューにある攻撃モーションが終了するまで、緊急の**Q**（回避）や**RMB**（ガード）へ移行できなくなります。

## キー配置の最適化とカスタマイズ設定

デフォルトのキー割り当てでも一般的なプレイには十分ですが、マウスのサイドボタンや押しやすいキーへリマップすることで、操作性と反応速度が大幅に向上します。防御や戦術アクションを追加のマウスボタンへ割り振れば、左手は**W, A, S, D**による移動とステップ回避だけに集中できます。

最近のゲーミングマウスには、サイドに2つの親指ボタン（マウス4・マウス5）が搭載されていることが多くあります。これらのボタンを活用することで、激しいクランバトル中の反応時間をコンマ数秒単位で短縮できます。高負荷な戦闘でも安定した動作を維持するため、キーのポーリングレートやクライアントの動作環境について、事前に[Roblox公式サイト](https://www.roblox.com)などで設定状況を確認しておくことをおすすめします。

| アクション | デフォルトキー | 推奨リマップ | 主なメリット |
| :--- | :--- | :--- | :--- |
| **フェイント / キャンセル** | R | マウスボタン4（親指） | 移動キーから指を離さずに攻撃をキャンセル可能 |
| **ダッシュ / 回避** | Q | 左Shift または マウス5 | 回避運動中も方向キー（WASD）を常に自由に操作可能 |
| **強攻撃** | F | マウス中クリック（ホイール押し込み） | 主要な攻撃アクションをすべて右手側に集約 |
| **体勢集中** | G | V または T | 戦闘キーへのアクセス時に誤爆するリスクを防止 |
| **インタラクト / 処刑** | E | E（デフォルト維持） | ドロップ回収や戦闘後のとどめ刺しに押しやすい位置 |

キー配置を最適化する際は、一度にすべてを変えるのではなく、1キーずつ変更していくのがコツです。レイアウトを一新すると、それまでのマッスルメモリーがリセットされて操作ミスを招きやすくなります。ランクマッチや大規模戦に挑む前に、トレーニング用のカカシや弱い敵を相手に10〜15分ほど練習し、新しいホットキーの感覚に指を慣らしていきましょう。

## 入力遅延とキー競合のトラブルシューティング

パリィキーを押したにもかかわらず、キャラクターが棒立ちのまま倒されてしまうことほどストレスの溜まる場面はありません。『Shogun's Reign』で操作の反応が鈍い、またはラグを感じる場合、ハードウェアまたはソフトウェア側のいくつかの要因が考えられます。

キーボードの「ゴースト（キーロールオーバーの限界）」は、旧型のキーボードで複数のキーを同時押しした際に入力が認識されなくなる現象です。本作では、**Shift**（ダッシュ）を押しながら**W**（前進）し、同時に**Q**（回避）や**RMB**（ガード）を入力する場面が頻繁に発生するため、非ゲーミング用のキーボードでは最後の入力が無視されてしまう場合があります。

```
入力遅延の主な原因:
- V-Sync（垂直同期）が有効になっており、フレームバッファ遅延が発生している
- バックグラウンドのCPU使用率が高く、フレームレートが低下している
- キーボードの同時押し制限（キーゴースト）
- ネットワークPingが不安定で、パリィ判定が同期ズレを起こしている
```

キー配置と併せて、マウスのカメラ感度も適切に調整されているか確認してください。感度が高すぎると、方向を指定して放つ斬撃のクロスヘアがブレてしまい、正しいキーを押していても攻撃が命中しない原因になります。対戦相手によってパリィのタイミングがズレると感じる場合は、混雑していないサーバーでレイテンシ（Ping）を確認してみましょう。

## Shogun's Reignのキー配置に関するよくある質問

### Shogun's Reignのキー配置をデフォルトに戻すにはどうすればよいですか？
ゲーム内設定メニューを開き、「Controls（操作設定）」タブを選択して「Reset to Default（初期設定に戻す）」をクリックしてください。確認画面で確定すれば、すべての移動および戦闘キーが元の設定に即座に復元されます。

### スマホやコントローラーでもキー配置をカスタマイズできますか？
現在、コントローラーおよびモバイル版のユーザーは、タッチUIや標準ゲームパッドに合わせた固定レイアウトが適用されています。PC版に比べるとボタンのリマップ自由度は限られますが、設定メニューからカメラ感度やボタンの透明度を調整することは可能です。

### 正しいタイミングでキーを押しているのにパリィが失敗するのはなぜですか？
パリィの成功判定は、ネットワーク遅延（Ping）と攻撃の飛来方向に影響されます。Pingが高い環境では、サーバーの処理遅延を考慮してわずかに早めに入力する必要があります。また、背後や側面からの攻撃はパリィできないため、必ず攻撃者を正面に捉えていることを確認してください。

### 1つのキーに複数の戦闘アクションを割り当てることはできますか？
いいえ、ゲームの仕様上、1つのボタンに複数の主要アクションを割り当てることやマクロの使用はサポートされていません。外部のマクロツール等を使用して複数の攻撃を自動化しようとすると、同期ズレの原因となるほか、ペナルティの対象となる可能性があります。各キーには必ず単一の機能を割り当ててください。
