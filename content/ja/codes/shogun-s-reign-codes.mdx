## Shogun's Reignコードの引き換え・適用手順

**Shogun's Reignコード**を入力する際は、プロモーションギフトを受け取るのか、アバターのセーブコードを読み込むのかに応じて、適切な画面を操作する必要があります。コードを正しく適用するために、以下の手順に沿って進めてください。

```
[メインメニュー] ➔ [キャラクターカスタマイズ] ➔ [スロット読み込み/インポート] ➔ [セーブコード貼り付け] ➔ [外見を適用]
```

### OCキャラクターセーブコードの読み込み手順

1. Robloxクライアントで*Shogun's Reign*を起動します。
2. タイトルロビー、またはワールド内の鏡／ワードローブから**Character Customization（キャラクターカスタマイズ）**メニューを開きます。
3. 管理パネルにある**Save / Load（セーブ／ロード）**タブを見つけます。
4. **Import Code（コードをインポート）**または**Load String（文字列を読み込む）**をクリックします。
5. 使いたいOCコードをコピーし、空白のテキストフィールドに貼り付けます（PCの場合は`Ctrl + V`、モバイルの場合は長押しして貼り付け）。
6. **Confirm（確認）**または**Import（インポート）**を押します。アバターが即座に指定のプリセットへと変化します。
7. サーバーを変更した際に変更内容が失われないよう、ローカルのキャラクタースロットのいずれかに外見を保存してください。

### プロモーションギフトコードの引き換え手順

1. 稼働中の*Shogun's Reign*ロールプレイサーバーに参加します。
2. UIの端にある**Settings（設定）**または**Menu（メニュー）**タブを開きます（通常、歯車や巻物のアイコンで表示されます）。
3. **Redeem Code（コード引き換え）**または**Promo（プロモ）**と書かれた入力ボックスを探します。
4. 現在有効なプロモーション用フレーズを入力または貼り付けます。
5. **Submit（送信）**をクリックすると、アイテムや通貨残高が即座に付与されます。

## Shogun's Reignコードに関するよくある質問（FAQ）

### Shogun's Reignのコードにはどのような効果がありますか？
*Shogun's Reign*におけるコードには主に2つの役割があります。プロモーションギフトコードは無料のゲーム内通貨や限定アクセサリーを提供し、キャラクターセーブコードは他のプレイヤーが作成した時代考証に沿った完成度の高いアバター衣装やプリセットをそのまま自分のキャラクターにインポートできます。

### 一度インポートしたキャラクターセーブコードは永久に残りますか？
はい。カスタマイズメニューにOCセーブコードをインポートすると、その外見が現在のアバターに直接適用されます。サーバーを退出した後もその見た目を永久に保持したい場合は、退出前にゲーム内の個人用プロファイルスロットのいずれかに保存してください。

### Shogun's Reignのコードを入力しても期限切れと表示されるのはなぜですか？
ゲームのアップデート時やフォロワー達成記念などで開発者が配布するプロモーションコードには、厳格な有効期限や最大引き換え回数が設定されていることがよくあります。プロモコードが使えない場合は、綴りに誤りがないか確認するか、開発者の最新アナウンスをチェックしてイベントが終了していないか確認してください。

### 自分でデザインしたキャラクターをShogun's Reignコードとして共有できますか？
もちろん可能です。ワードローブメニューでキャラクターの服、髪型、アクセサリーのカスタマイズが完了したら、**Export（エクスポート）**ボタンをクリックしてください。固有の英数字コードが生成されるので、それをコピーしてフレンドと共有したり、コミュニティに投稿したりすることができます。
