## Entendendo os Códigos em Shogun's Reign: Códigos Promocionais vs. Códigos de Save de Personagem

Em *Shogun's Reign*, o principal formato de código consiste em **strings alfanuméricas de save de personagem**. Compartilhar essas strings permite que novos jogadores carreguem instantaneamente visuais idênticos, quimonos sobrepostos e estruturas faciais exclusivas.

Além disso, os desenvolvedores ocasionalmente lançam códigos promocionais de eventos durante atualizações, marcos e fases de teste. Compreender com qual sistema você está interagindo evita confusões ao colar sequências longas na interface do usuário.

## Como Resgatar Códigos de Shogun's Reign Passo a Passo

Inserir **shogun's reign codes** requer navegar pela interface adequada, dependendo se você está resgatando presentes promocionais ou carregando uma string de save de avatar. Siga estes procedimentos passo a passo para garantir que seus códigos sejam aplicados corretamente.

```
[Menu Principal] ➔ [Personalização de Personagem] ➔ [Carregar / Importar Slot] ➔ [Colar Código de Save] ➔ [Aplicar Aparência]
```

### Carregando uma String de Save de Personagem OC

1. Abra *Shogun's Reign* no cliente do Roblox.
2. No lobby inicial ou usando um espelho/guarda-roupa no mundo do jogo, abra o menu **Personalização de Personagem** (Character Customization).
3. Localize a aba **Salvar / Carregar** (Save / Load) no painel de gerenciamento.
4. Clique em **Importar Código** (Import Code) ou **Carregar String** (Load String).
5. Copie a string do OC desejado e cole-a no campo de texto vazio (`Ctrl + V` no PC ou pressionando para colar no celular).
6. Pressione **Confirmar** (Confirm) ou **Importar** (Import). Seu avatar se transformará instantaneamente na predefinição indicada.
7. Salve a aparência em um dos seus slots de personagem locais para evitar perder as alterações ao trocar de servidor.

### Resgatando Códigos Promocionais de Presente

1. Entre em um servidor ativo de roleplay de *Shogun's Reign*.
2. Abra a aba **Configurações** (Settings) ou **Menu** localizada na borda da interface do usuário (frequentemente representada por um ícone de engrenagem ou pergaminho).
3. Procure pela caixa de diálogo identificada como **Resgatar Código** (Redeem Code) ou **Promo**.
4. Digite ou cole a frase promocional atual.
5. Clique em **Enviar** (Submit) para receber instantaneamente seus itens ou saldo em moeda.

### Solução de Problemas Comuns de Importação e Erros de Código

| Mensagem de Erro / Problema | Causa Subjacente | Solução Verificada |
| :--- | :--- | :--- |
| **"Invalid Code Format"** | Hífen ausente ou final cortado da área de transferência | Copie a string novamente por completo a partir da fonte, garantindo que não haja espaços extras no final. |
| **"Code Already Redeemed"** | O código promocional é limitado a um único uso por conta | Verifique seu saldo ou inventário; a recompensa já foi entregue. |
| **"Asset Failed to Load"** | Uma textura de roupa específica está passando pela moderação do Roblox | Aplique novamente uma camada padrão de quimono através do editor de guarda-roupa no jogo. |
| **"Save Slot Locked"** | O jogador atingiu o limite máximo de perfis de save gratuitos | Sobrescreva um slot não utilizado existente ou libere espaço de armazenamento do criador. |

## Perguntas Frequentes Sobre Códigos de Shogun's Reign

Se um código promocional falhar, verifique a grafia ou consulte os anúncios recentes dos desenvolvedores para confirmar se o evento já terminou.

### Posso compartilhar meus próprios designs de personagens como códigos de Shogun's Reign?
